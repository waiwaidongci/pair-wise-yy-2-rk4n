# 赛鸽血统环号登记站 · 鸽棚容量与迁入复核台

运行：

```bash
npm start
```

访问 `http://localhost:3024`。

## 功能

- **档案与血统**：足环建档、父母子代查询、转让、疫苗与归巢成绩。
- **棚位容量**：每棚有容量、启用/停用状态、通风等级（A>B>C）。档案入棚前必须占用有效棚位，停用、满员或通风等级不符一律拒绝且不改变原归属。
- **迁入复核台**：迁入走"申请 → 确认"两段流程。申请通过规则校验后预留棚位；确认后档案才划入目标棚。同一请求编号重复或并发提交只采用首次结果（含拒绝结果）。
- **超配处理**：调低容量使棚超配时，未完成迁入自动冻结、在棚档案保留并标记待复核；调高容量或取消迁入释放棚位后自动恢复。
- 棚位占用、待迁移清单与单鸽履历持久化在 `data/pigeons.json`，重载后保持一致。

## 结构

- `server.js` — HTTP 路由接线
- `src/rules.js` — 规则判断（准入、占用、超配派生状态）
- `src/store.js` — 档案存储（持久化、变更串行化、迁入幂等）
- `src/page.js` — 页面反馈（容量面板、复核台、待复核清单）

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 鸽棚占用、档案、迁入清单总览 |
| POST | `/api/pigeons` | 建档入棚（校验棚位准入） |
| POST | `/api/lofts` / PATCH `/api/lofts/:name` | 新建 / 调整鸽棚（容量、状态、通风） |
| POST | `/api/move-ins` | 申请迁入（幂等，需 `requestId`） |
| POST | `/api/move-ins/:id/confirm` / `/cancel` | 确认 / 取消迁入 |
| GET | `/api/pigeons/:ring/relation` | 血统与单鸽迁入履历 |
